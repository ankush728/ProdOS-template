> This is a reference file showing the correct Drop Zone format.
> It will NOT be processed by the Triage Agent (filename doesn't match pattern).
> Copy this format into a dated file: dropzone_YYYY-MM-DD.md

---

DATE: 2026-03-08
SOURCE: transcript
RAW:
[Paste your transcript here. Can be any format: plain text, Zoom, Otter.ai, VTT, etc.

---

DATE: 2026-03-08
SOURCE: email

[Paste the email thread here. Include From/To/Subject if available.

---

SOURCE: notes
RAW:
[Brain dump, bullet points, meeting debrief — any format.
This is for manual notes you type up yourself.]
