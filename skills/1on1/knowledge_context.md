# 1:1 Skill - Context Loading Guide

This file defines what work context to load for 1:1 prep based on person's role.

---

## Context Loading by Role

### CEO / Executive Leadership

**Always load:**
- GOALS.md (Q1/Q2 progress, strategic objectives)
- tasks/active.md (high-level initiatives you're driving)
- Latest Strategy moat portfolio (competitive positioning)
- Person's PROFILE.md (from `meetings/1on1s/[Person]/PROFILE.md`) — communication style, hot buttons, current priorities, relationship history

**Sometimes load:**
- Recent VOC synthesis (customer traction evidence)
- Recent CTO moat validations (technical confidence)
- Recent PowerPoint presentations (what you're communicating)
- `shared/knowledge/truth_pack/TP_07 Competitive Intelligence Registry.md` — When competitive topics are on the agenda

**Why:** CEOs care about strategic progress, moats, customer momentum.

**Present context as:**
- Strategic updates (GOALS progress, moat portfolio)
- Customer evidence (VOC findings)
- Technical validation (CTO assessments)

---

### Board / Investors

**Always load:**
- Latest Strategy moat portfolio (competitive advantage)
- GOALS.md (metric progress)
- Recent VOC outputs (customer validation)

**Sometimes load:**
- Recent CTO moat validations (technical defensibility)
- Recent PowerPoint presentations (board deck context)

**Present context as:**
- Moat progress (which moats strengthening)
- Customer traction (interview count, validation)
- Technical confidence (CTO assessments)
- Metrics (GOALS progress percentages)

---

### Direct Reports

**Always load:**
- tasks/active.md (their projects + yours that affect them)
- GOALS.md (how their work connects to objectives)

**Sometimes load:**
- Recent outputs relevant to their projects
- PRD if they're working on specific feature

**Why:** Direct reports need context on their work, blockers, development.

**Present context as:**
- Their projects status
- Blockers you can help remove
- Development opportunities
- Alignment with goals

---

### Peers (Other VPs)

**Always load:**
- tasks/active.md (shared initiatives)
- GOALS.md (cross-functional alignment)

**Sometimes load based on their domain:**
- **If VP Engineering:** Recent CTO outputs (technical decisions)
- **If VP Sales:** Recent VOC outputs (customer insights), Strategy (positioning)
- **If VP Marketing:** Recent Strategy outputs (competitive positioning)

**Why:** Peers need coordination, alignment, shared context.

**Present context as:**
- Shared initiatives
- Dependencies
- Alignment opportunities
- Recent relevant outputs

---

### External Stakeholders (Partners, Vendors)

**Always load:**
- tasks/active.md (items involving them)

**Sometimes load:**
- Recent outputs if relevant to partnership

**Why:** External stakeholders need transactional context.

**Present context as:**
- Action items
- Deliverables
- Next steps

---

## Context Loading Best Practices

**Efficiency:**
- Load only what's relevant to this person's role
- Prioritize recent outputs (last 30 days)
- Don't load entire output directories (just summaries)

**Presentation:**
- Summarize, don't dump (bullets, not full text)
- Highlight what matters to them
- Connect to their priorities

**Fallback:**
- If role unclear, default to CEO/Executive pattern
- Can always load less context if needed
- Better to under-load than overwhelm prep

## Notes

- Context loading should take <30 seconds
- Load summaries, not full files
- Personalize to role and relationship
- If in doubt, load less (can always add more)
